  that replaces free-text LLM generation with constrained candidate selection to eliminate

  score and a regression-tested evaluation harness.

  Lambda execution, with a replay engine that turns successful runs into reusable recipes.

  Llama 2 / Mistral with LoRA and QLoRA for targeted performance under compute constraints.
